# Photos du site

Photos générées (IA, Canva) dans la charte : crème / vert forêt / or, lumière naturelle, aucun visage identifiable.
Les fichiers `preview-*.jpg` du dossier sont des **aperçus basse définition** (≈ 200 px). Les versions HD sont dans le Canva du compte qui a préparé le dossier : ouvrir chaque lien, télécharger, et enregistrer dans ce dossier sous le **nom HD** indiqué (sans `preview-`). Le site utilise automatiquement la HD si elle est présente.

## Règles d'usage
- Toujours un voile (crème 70-85 % ou dégradé vert-900 → transparent) quand un texte passe sur une photo.
- Ne pas utiliser de photo en pleine largeur tant que seule la version `preview-` est disponible : utiliser le dégradé de la charte à la place.
- Remplacer `relances-telephone.jpg` par le **portrait réel de Laurine** dès qu'il est disponible.
- Visuels Instagram de `assets/references/` : **références de style uniquement**, ne pas les intégrer comme images sur le site (texte incrusté non accessible).
